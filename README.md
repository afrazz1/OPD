# 🗺️ GroupMap - Встречайтесь с друзьями!

Современное веб-приложение для организации встреч с друзьями в реальном времени с функциями карты, чата и AI рекомендациями.

## 🎯 Основные возможности

✨ **Управление группами** - создавайте и управляйте группами встреч  
🗺️ **Карта в реальном времени** - видите позицию себя и друзей на интерактивной карте  
💬 **Чат** - общайтесь с участниками группы в реальном времени  
🤖 **AI Рекомендации** - искусственный интеллект подберет лучшие места для встреч  
🎉 **Места развлечений** - каталог интересных мест для посещения  
🎨 **Красивый интерфейс** - дружелюбный и приятный дизайн  

## 📋 Требования

- Node.js (v14+)
- npm или yarn
- Современный браузер с поддержкой геолокации

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
npm start
```

Или для развития с автоматической перезагрузкой:

```bash
npm run dev
```

Сервер запустится на `http://localhost:5000`.

### 4. Развертывание на сайте

Это приложение можно разместить на любом Node.js-хостинге (Heroku, Render, Railway, VPS и т.п.).

1. Перенесите папку проекта на сервер.
2. Установите зависимости:

```bash
npm install
```

3. Запустите приложение:

```bash
npm start
```

4. Откройте сайт по адресу вашего домена.

Клиент теперь использует текущий URL сайта для API и WebSocket, поэтому приложение будет работать не только на `localhost`, но и на удалённом хостинге.

### 5. Развёртывание на GitHub Pages

Это приложение может быть размещено на GitHub Pages как статический frontend из папки `public`.

1. Убедитесь, что в `package.json` добавлен `homepage` и скрипт `deploy`.
2. Установите зависимости:

```bash
npm install
```

3. Запустите деплой:

```bash
npm run deploy
```

4. Откройте сайт по адресу:

```text
https://afrazz1.github.io/OPD/
```

> Важно: GitHub Pages поддерживает только статические файлы. Полный функционал приложения, требующий backend и WebSocket, не будет работать на Pages без отдельного сервера.

### 3. Открытие в браузере

Откройте в браузере:
```
http://localhost:5000
```

## 🔐 Функции авторизации

### Регистрация
1. Введите имя пользователя, email и пароль
2. Нажмите "Зарегистрироваться"
3. Вы автоматически войдете в аккаунт

### Вход
1. Введите email и пароль
2. Нажмите "Войти"

## 👥 Управление группами

### Создание группы
1. Нажмите кнопку "Создать группу"
2. Введите название и описание
3. Подтвердите создание

### Открытие группы
1. Кликните на карточку группы
2. Вы будете перенаправлены на вкладку с картой

## 🗺️ Использование карты

- Карта показывает ваше текущее местоположение (синий маркер)
- Друзья отображаются как красные маркеры
- Зум можно регулировать колесом мыши
- Кликните на маркер для дополнительной информации

## 💬 Чат

1. Перейдите на вкладку "Чат"
2. Введите сообщение в поле внизу
3. Нажмите "Отправить" или Enter
4. Сообщения отображаются в реальном времени

## 🤖 AI Рекомендации

1. Перейдите на вкладку "AI"
2. Нажмите "Получить рекомендации"
3. AI предложит лучшие места на основе ваших предпочтений
4. Нажмите на рекомендацию чтобы перейти на карте

## 🌍 Места развлечений

На вкладке "Места" вы можете:
- Просмотреть каталог интересных мест
- Видеть рейтинги и расстояния
- Кликнуть на место для навигации

## 🐛 Решение проблем

### Карта не загружается
- Убедитесь, что браузер имеет доступ в интернет
- Проверьте консоль браузера на ошибки

### Геолокация не работает
- Разрешите браузеру доступ к геолокации
- Используйте HTTPS или localhost

### Сервер не запускается
- Проверьте, что Node.js установлен: `node --version`
- Убедитесь, что порт 5000 свободен
- Удалите node_modules и переустановите: `rm -rf node_modules && npm install`
