# 📁 Структура проекта GroupMap

## 📂 Директория проекта

```
prototip/
├── 📄 package.json           # Зависимости NPM
├── 📄 server.js              # Сервер Node.js/Express
├── 📄 .env                   # Переменные окружения
```

## 📋 Описание файлов

### 🔧 Конфигурационные файлы

**package.json** - Главный файл конфигурации проекта
- Описание проекта
- Список зависимостей
- NPM скрипты для запуска

**server.js** - Node.js сервер (4 части)
1. **Express приложение** - инициализация
2. **REST API endpoints** - обработка HTTP запросов
3. **Socket.io серверная часть** - реал-тайм события
4. **Запуск сервера** на порту 5000

**.env** - Переменные окружения
- PORT=5000
- NODE_ENV=development

**.gitignore** - Файлы которые игнорируются Git
- node_modules/
- .env файлы
- Логи и кеш

### 📱 Фронтенд файлы (в папке `public/`)

**index.html** - HTML структура (3 экрана)
1. **authScreen** - авторизация (вход/регистрация)
2. **groupsScreen** - список групп
3. **groupMapScreen** - карта с вкладками

**styles.css** - Стили (6 разделов)
- Переменные CSS (цвета, тени)
- Авторизация
- Группы и карточки
- Карта и боковая панель
- Ч ат, места, AI
- Отзывчивость

**app.js** - JavaScript логика (8 разделов)
- Глобальные переменные
- Инициализация Socket.io
- Авторизация (вход/регистрация)
- Управление группами
- Карта и геолокация
- Чат функции
- Переключение вкладок
- Утилиты

## 💾 Хранилище данных

**В памяти сервера (временное):**
- `groups` - Map с группами
- `users` - Map с пользователями
- `messages` - Map с сообщениями
- `userLocations` - Map с координатами

## 🔌 API Endpoints

### Авторизация
- `POST /api/register` - Регистрация
- `POST /api/login` - Вход

### Группы
- `POST /api/groups` - Создание
- `GET /api/groups/:userId` - Получить все
- `GET /api/groups/:groupId/info` - Информация
- `POST /api/groups/:groupId/add-member` - Добавить

### Сообщения и рекомендации
- `GET /api/groups/:groupId/messages` - История чата
- `POST /api/ai/recommend` - AI рекомендации

## 🔌 Socket.io События

### Клиент → Сервер
- `join-group` - присоединиться к группе
- `update-location` - отправить координаты
- `send-message` - отправить сообщение

### Сервер → Клиент
- `location-updated` - обновление позиции
- `message-received` - новое сообщение
- `user-joined` - пользователь присоединился

## 🚀 Процесс запуска

1. Сервер инициализирует Express и Socket.io
2. Слушает на порту 5000
3. Обслуживает статические файлы из `public/`
4. Готов к получению HTTP и WebSocket запросов
